# KittenFish repositories

The existing code and checkpoints have been reorganised by generation:

- [kittenfishv0](https://github.com/crazykitten43/kittenfishv0): CNN checkpoint, evaluator, search and UCI engine.
- [kittenfishv0.5](https://github.com/crazykitten43/kittenfishv0.5): L4 SE-ResNet checkpoint, inference, alpha-beta/beam searches and UCI engine.
- [kittenfishv1](https://github.com/crazykitten43/kittenfishv1): NNUE engine.
- [kittenfishtraining](https://github.com/crazykitten43/kittenfishtraining): training code in v0, v0.5 and v1.

Each engine repository documents its lichess-bot setup. Original files remain available in Git history.
